# Muriithi S. Kiragu & Co. Advocates

Static, responsive law-firm website built from the supplied brand assets and firm information. The structure follows the Cecilia Mwaura demo pattern: editorial hero, practice cards, counsel profile, insights, consultation CTA and dedicated About / Practice Areas / Advocate / Insights / Contact pages.

## Local check

```bash
npm run check
npm run build
```

Open `index.html` directly for a quick preview, or deploy with Vercel.
